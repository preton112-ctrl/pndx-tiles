# Tile Selection — PNDX Studio & Design

เว็บให้ลูกค้าเลือกกระเบื้องจาก ไทวัสดุ · โฮมโปร · ดูโฮม จัดลงห้อง/จุดติดตั้ง คำนวณจำนวนกล่อง และบันทึกเป็น PDF

- `index.html` — หน้าเว็บ
- `data/tiles.js` — รายการกระเบื้องและสเปกตามหน้าร้าน
- `data/prices.js` — ราคาและสต็อก อัปเดตทุกเช้าประมาณ 07:00 น.
- `img/` — รูปย่อกระเบื้อง · `assets/` — โลโก้และตัวสร้าง PDF

ราคาเป็นราคาตามหน้าเว็บร้าน ณ เวลาที่อัปเดต ไม่ใช่ราคาสด ตรวจที่หน้าร้านอีกครั้งก่อนสั่งซื้อ
